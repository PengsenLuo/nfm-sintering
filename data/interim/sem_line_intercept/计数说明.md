# 线截距法计数说明（5000× 脊线分水岭验证）

## 要验证什么

脊线分水岭在 5000× 上目测优于原来的局部阈值分割，但**没有 ground truth**，
"看起来对"不等于"对"。线截距法（ASTM E112）是金相晶粒度的标准手工方法，
专为"晶粒已连成一片、无法逐颗描边"的组织设计，正好对应这里的处境，
而且完全独立于任何自动分割。

## 验证设计：不比尺寸，比同一次测量

如果拿自动分割的粒径去和手工截距长度比，中间要引入形状因子换算，
而换算系数本身就是个可争论的自由度——对不上也说不清是方法错了还是系数错了。

所以改成直接比**同一组测试圆上的截点数**：

- 你数：测试圆与晶界的交点数 `P_manual`
- 程序数：脊线分水岭的分区边界与**同一条圆**的交点数 `P_auto`

同一个量、同一条曲线、两次独立测量，不需要任何换算。
平均截距长度 L̄ = 圆周总长 / P，所以 P 对上了，L̄ 就对上了。

## 为什么用圆而不是直线

直线有端点，线段末端常落在晶粒中间，需要做端点修正；圆没有端点，
不存在这个问题。而且圆对所有方向等权，自动消除组织取向造成的各向异性偏差。
这是 ASTM E112 里的 Hilliard / Abrams 圆截距法。

## 晶界的定义（重要，先读这一段）

严格意义上，晶界是两个取向不同的晶粒相接的**内部界面**，SEM 二次电子像
看不到内部界面。你在图上能看见它，靠的是**热蚀沟（thermal groove）**：
烧结时晶界与自由表面相交处，表面扩散把材料从沟底搬走，形成一道浅槽，
在图上表现为**一条暗线，两侧常伴亮边**（边缘效应）。

所以本次计数里：

> **晶界 = 热蚀沟的痕迹**（暗线 + 两侧亮边、且两侧材料连续）。

**不算晶界的三类：**

- 同一晶粒两个刻面的交线（棱）——那些规整多面体上的棱线属于此类
- 表面小突起的轮廓——按上一轮确认，突起不影响颗粒尺寸
- 孔隙 / 阴影的边缘——那是空隙边界，不是晶界

**你问的"中间一段模糊区域"——算一个界面，不是两个。**
一条界面 = 一次穿越。测试圆从晶粒 A 走到晶粒 B，穿过这段模糊区，计 **1**。
不要把"A 的边缘"和"B 的边缘"数成两次——那是把一个界面数了两遍。
判断靠**物质是否连续**：

| 现象 | 判断 | 计数 |
|---|---|---|
| 暗线两侧有亮边、材料连续（沟槽） | 晶界 / 烧结颈 | **1** |
| 较宽暗区，看得出是空洞、没有底 | 孔隙 | **0，该段弧本就是灰的，跳过** |
| 离焦 / 荷电 / 析出覆盖导致糊 | 成像问题 | 记在 notes，我按缺失处理 |

最好用的一条经验：**看有没有亮边**。热蚀沟是凹槽，两侧棱会亮；
纯孔隙阴影没有这个特征。

## 怎么数

打开 `LI_<样本号>.png`（分辨率 2800 px，放大后计数）。对 A（红）、B（青）、
C（黄）三个圆分别数：**沿着实色圆弧走，穿过了多少条晶界**。

填进 `计数表.csv` 的 `P_manual` 列。

几条规则：

- **灰色弧段直接跳过**——那是程序判定的孔隙/背景暗区，那里没有晶界，
  你不用数，程序也不在灰段统计。手工与自动口径由此完全对齐。
- 圆与晶界相切、擦边而过的，计 0.5
- 一条界面只计一次（见上一节的"模糊区算一个"）
- 三个圆是独立的，**如果某张图太密，只数 A 或只数 C 也可用**，
  其余留空即可，程序按已填的圆做比较

## 圆半径是怎么定的

ASTM 建议每视场截点数在 50–150 之间：太少统计不稳，太多人工易错。
脚本用脊线分水岭的初步结果自适应选半径，目标 60 个左右（C03-L 偏密，约 149，
可只数一个圆）。

需要说明：**用自动结果来定圆的大小不会污染这次比较**——它只决定在哪儿画圆，
不影响你在这条圆上数出多少个交点。

## 样本选择

C21-S / C26-L / C14-M / C07-S / C03-L，覆盖热预算与前驱体两个方向的
极端与中间。

## 数完之后

把 `计数表.csv` 给我，我做三件事：

1. 逐样本比对 `P_manual` 与 `P_auto`，看系统偏差有多大、是否随晶粒尺寸变化
2. 若一致，脊线分水岭可全量跑 51 样，`D_pri_sem` 这条线不再需要可分割性门控
3. 若不一致，看偏差是常数比例（可校正）还是随样本变化（方法有系统缺陷）

**先别看 `_auto_勿先看.csv`**，里面是程序的答案。
